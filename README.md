# Book & Manage - Frontend

## requirements 
### Node must be installed
- v22.11.0 [download Node from here](https://nodejs.org/en/blog/release/v22.11.0) 


## setup

- create .env file as per given .env.example file 

- Clone Repository
  ```
  git clone  https://github.com/dhruv4023/studioApp
  ```

- install npm modules
  ```
  npm install
  ```

- to run this application in local env
  ```
  npm run dev
  ```
